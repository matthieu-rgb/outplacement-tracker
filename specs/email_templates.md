# Email Templates - outplacement-tracker v0.1

Four email templates used by the two Power Automate Flows.
Variables between double curly braces `{{variable}}` are injected by Power Automate at send time.

Variable reference:
- `{{prenom}}` : field `Participants.prenom`
- `{{nom}}` : field `Participants.nom`
- `{{date_rdv}}` : field `Participants.date_prochain_rdv`, formatted DD.MM.YYYY
- `{{lien_formulaire}}` : unique Microsoft Forms link generated by the J-5 Flow
- `{{nom_conseillere}}` : derived from `Participants.id_conseillere` (M365 account display name)
- `{{prenom_participant}}` : field `Participants.prenom`
- `{{nom_participant}}` : field `Participants.nom`
- `{{lien_pdf_sharepoint}}` : URL of the PDF file in the participant's SharePoint library

## Power Automate configuration notes

- **Sender** : use a shared mailbox (e.g. transfer@societe.de) configured by the M365 administrator. Do not use an individual user's personal account.
- **Encoding** : UTF-8 for all templates. German umlauts (ü, ö, ä, ß) are supported in UTF-8 by the Office 365 Outlook connector and common IMAP clients. Technical identifiers (SharePoint columns, Tag values) remain in ae/oe/ue/ss.
- **Attachment** (Templates 3 and 4) : the cumulative PDF is attached via the Power Automate "Add an attachment" action. Recommended maximum size: 10 MB (well within range for a 12-month PDF).
- **Form link** (Templates 1 and 2) : the link is generated by the "Get the response details" action or via a pre-configured variable. It is not reusable across participants.
- **Testing** : always test sending to a dedicated test address before going live. Never use a real personal address in test variables.
